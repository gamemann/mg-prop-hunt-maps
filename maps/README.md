# Writing a map

A map is one JSON file in this directory. A server reads every `.json` here at boot (and again on `ph_reload`), checks it, and plays it; a file it refuses is listed by `ph_maps` with the reason, and every other map still plays. Clients never read these files: the server sends the map it is playing to each of them when the map changes.

The maps shipped here are generated by [`../tools/build_maps.py`](../tools/build_maps.py) and should be changed there, not here: `tools/build_maps.py --check` fails when a file is not what it would write. The builder is also the quickest way to write a new map, because a wall with its doors and windows, a room with its floor, ceiling and light, and a furnished classroom are one call each. What follows is the format itself.

Every length is metres, every angle degrees, every time seconds. A position is `[x, y, z]`, y is up, and the floor of a building is at y 0.

## The document

```json
{
	"format": 1,
	"kind": "prophunt_map",
	"id": "ph_my_map",
	"name": "My Map",
	"author": "you",
	"blurb": "One line, shown when the map starts.",
	"round_seconds": 0,
	"hide_seconds": 0,
	"kill_y": -20.0,
	"environment": {
		"sky_top": [0.32, 0.52, 0.82], "sky_horizon": [0.72, 0.82, 0.92], "ground": [0.35, 0.33, 0.30],
		"sun_pitch": -55, "sun_yaw": 30, "sun_energy": 1.1, "sun_colour": [1.0, 0.96, 0.88],
		"ambient": [0.62, 0.66, 0.72], "ambient_energy": 0.55, "fog": 0.0
	},
	"boxes": [],
	"props": [],
	"lights": [],
	"spawns": {"props": [], "hunters": []}
}
```

- `id` is lowercase a to z, 0 to 9 and `_`. A file whose id is `ph_practice` replaces the built-in practice house.
- `round_seconds` and `hide_seconds`: how long this map's rounds and hides last; 0 is the server's own (`ph_round_seconds`, `ph_hide_seconds`), and the server's is always the ceiling.
- `kill_y`: anybody below it is out. Put it under anything a player could fall off.
- `environment`: every field is optional and the values above are the defaults. `fog` is a density; 0.0025 is a light haze over a big outdoor map, and 0.008 already hides everything past forty metres.

## Boxes

The building: floors, walls, ceilings, roofs, glass, a pool, a painted line.

```json
{"at": [0, 1.5, -8], "size": [12, 3, 0.2], "mat": "paint", "tint": [0.95, 0.93, 0.85], "yaw": 0, "solid": true, "visible": true}
```

- `at` is the box's **centre**; `size` is its width, height and depth before `yaw` turns it.
- `mat` is one of: `wood_floor`, `parquet`, `gym`, `tile`, `tile_check`, `tile_small`, `carpet`, `paint`, `plaster`, `ceiling`, `brick`, `stone`, `concrete`, `sidewalk`, `asphalt`, `grass`, `dirt`, `sand`, `rubber`, `roof`, `wood`, `metal`, `locker`, `chalkboard`, `whiteboard`, `glass`, `water`, `line`, `hedge`, `fabric`, `flat`. An unknown name is drawn as `flat`. Textures are laid in world space, so two boxes of the same material meet without a seam.
- `tint` multiplies the material's colour.
- `"solid": false` for anything a player walks through: water, a painted line, a light's glow.
- `"visible": false` for a collider with nothing drawn: an invisible wall at the edge of the map.

## Props

The furniture, the plants, the rocks: everything a prop player can hide among and become.

```json
{"id": "furniture_chair", "at": [3.6, 0, 1.2], "yaw": 90, "pitch": 0, "roll": 0}
```

- `id` is a prop from mg-prop-hunt's `props/catalogue.json` (`furniture_*` are Kenney's Furniture Kit, `nature_*` the Nature Kit; the file has every id with its size). An id the game does not have is built as nothing and logged.
- `at` is the middle of the prop's **footprint on whatever it stands on**, so a chair is placed by where it stands and a lamp on a table by the table's top.
- A prop's front faces +Z at yaw 0. So against a wall at the smaller z it faces into the room at yaw 0, against one at the larger z at 180, at the smaller x at 90 and at the larger x at -90.
- Props are solid and block a hunter's shot. A hunter who shoots one pays for it in health, so a room full of furniture is a room where guessing costs.

## Lights

```json
{"at": [0, 2.9, -4], "range": 9, "energy": 1.1, "colour": [1.0, 0.95, 0.85]}
```

An omni light. Indoors, one per room of about eight by eight metres, just under the ceiling. Browsers draw at most eight lights on any one surface, so a big room wants a few strong lights more than many weak ones.

## Spawns

```json
"spawns": {
	"props": [{"at": [-5, 0.05, 0], "yaw": 90}],
	"hunters": [{"at": [7, 0.05, 0], "yaw": -90}]
}
```

`at` is where the player's feet go. A map needs at least one of each; with more players than spots, later ones are placed in rings round the first. Give the props six or more spread through the map, and the hunters three or more somewhere the props cannot watch them from. Keep spawns clear of props: mg-prop-hunt's `examples/headless_maps.tscn` fails a spawn with no floor under it or with something in the way, and the builder moves its own.

## Checking a map

From mg-prop-hunt:

```bash
./game.sh test headless_maps                                   # every map: wire size, props, spawns, nothing floating
tools/shot.sh --view=overview --ph-map-ids=ph_my_map           # look at it from above
tools/shot.sh --view=room --ph-map-ids=ph_my_map --at=0,1.7,0 --look=5,1,5
```

`headless_maps` lists every map it checks by id; add a new one to its `MAPS` list.
